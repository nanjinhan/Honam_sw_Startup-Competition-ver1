# 보듬길 — 함께라서 좋은 여행

노란색을 메인으로 한 가족 여행 프론트엔드 데모입니다. 제공된 길안내1 디자인과 교통약자 동반 가족 여행 기획안을 바탕으로 제작했습니다.

## Vercel 배포

1. https://vercel.com/new 에서 GitHub 계정을 연결합니다.
2. `nanjinhan/Honam_sw_Startup-Competition-ver1` 저장소의 **Import**를 선택합니다.
3. Root Directory는 저장소 루트(`./`)로 두고 **Deploy**를 누릅니다.
4. 완료 후 제공되는 `vercel.app` 주소를 공유합니다.

`vercel.json`에 Vite, 설치 명령 `pnpm install --frozen-lockfile`, 빌드 명령 `pnpm build`, 출력 폴더 `dist`를 설정했습니다. Node.js는 24.x를 사용합니다. 환경 변수와 백엔드 설정은 필요하지 않습니다.

페이지 이동은 해시 주소(`#family`, `#plan` 등)를 사용하므로 별도 경로 재작성 설정이 필요하지 않습니다. GitHub 연결 후 `main` 브랜치에 올리는 변경 사항은 Vercel에서 자동 배포됩니다.

## 같은 와이파이에서 보기

현재 실행 주소: **http://192.168.0.65:4187/**

같은 와이파이에 연결된 휴대폰이나 컴퓨터에서 위 주소를 열면 됩니다. 기존 4173 포트는 사용하지 않습니다. 이 컴퓨터가 켜져 있고 와이파이에 연결되어 있어야 합니다. 컴퓨터의 IP 주소가 바뀌면 주소도 바뀝니다.

서버를 다시 켤 때는 `start-demo.cmd`를 실행하거나 아래 명령을 사용하세요. 이미 실행 중이면 같은 포트로 두 번 실행하지 않아도 됩니다.

```sh
corepack pnpm preview --host 0.0.0.0 --port 4187 --strictPort
```

코드를 수정한 뒤에는 `corepack pnpm build`로 데모 파일을 다시 만드세요.

## 실행

Node.js 24.x를 사용합니다.

```sh
corepack pnpm install
corepack pnpm dev --port 5187
```

브라우저에서 http://127.0.0.1:5187 을 엽니다.

```sh
corepack pnpm typecheck
corepack pnpm build
corepack pnpm preview --port 5187
```

## 시연 순서

1. 홈에서 '부모님과 함께' 또는 '유모차와 함께'를 선택합니다.
2. 동행자를 추가·수정하고, 이동 조건과 여행 시간을 고릅니다.
3. 조건 확인 후 관광·맛집·카페·체험 장소를 검색하거나 필터링합니다.
4. 장소를 여행에 담아 일정을 만듭니다. 선택한 시간 안에 들어오는 장소를 배치합니다.
5. 일정 순서 변경, 장소 삭제, 대안 코스, 저장을 눌러봅니다.
6. 일정 공유에서 링크 복사 또는 큰 글씨 미리보기를 확인합니다.
7. 장소 상세에서 접근성 정보·도착 준비를 보고, 사진 또는 메모로 제보를 체험합니다.

## 데모 범위

- React + TypeScript + Vite 프론트엔드만 있습니다. 별도 백엔드나 API 키가 필요하지 않습니다.
- 모바일·태블릿·데스크톱 반응형 화면, 키보드 조작, 대화상자 초점 관리, 모션 줄이기를 지원합니다.
- 장소 저장과 명시적으로 저장한 일정은 이 브라우저의 localStorage에 보관합니다.
- 가족 정보는 화면 상태에만 유지하며, 제보 사진·내용도 외부로 전송하지 않습니다.
- 자연어 입력은 예시 키워드 선택입니다. 실제 AI 분석이나 건강 상태 추론을 하지 않습니다.
- 장소·소요 시간·접근성 판정은 **시연용 예시**입니다. 지도는 위치 개념도이며 실제 지도·실시간 정보·관광지 내부 길찾기가 아닙니다.
- 사진은 제공된 디자인 코드의 참고 이미지입니다. 상세 화면에 실제 장소와 다를 수 있음을 표기했습니다.
- 공유 링크는 장소와 출발 시간을 URL에 담습니다. 로컬 주소는 같은 컴퓨터에서만 열립니다. 호스팅 사이트를 공유할 때는 사이트의 접근 권한도 확인해야 합니다.

## 참고 UI

- Cult UI Hero Color Panels: 노란색 셰이더 배경으로 재구성.
- Cult UI Direction Aware Tabs: 슬라이딩 선택 표시를 제어 가능한 버튼 그룹으로 변형.
- React Bits BlurText: 첫 화면 제목의 등장 효과.
- React Bits AnimatedContent: 가족 카드의 등장 효과, 모션 줄이기 지원 추가.
- React Bits SpotlightCard: 장소 카드와 여행 설정 카드의 반응 효과.
